# Architecture 06 — Autonomous Web Frontend & Backend API Application Engine (`src/zcg/web/`)

> **Normative Specification — Subsystem 6 (`src/zcg/web/{http,auth,ui,ops,capabilities}/*.py` & `src/zcg/web/assets/{css,js,img,templates}/`)**
>
> This specification defines the zero-dependency, `100%` domain-agnostic Python 3.14 Web Frontend and Backend API constructor (`src/zcg/web/`) powering Zero-Cloud Node Reference Dashboards, domain plugins (`src/zcg/plugins/`), and standalone web/API applications. ### 1.1. Design Rationale: Why Pure Python 3.14 Hypermedia + ES2024 Islands Over Multi-Framework Sprawl

The table below contrasts `zcg.web` against conventional multi-framework web stacks across sovereignty, supply-chain durability, and security boundaries:

| Architectural Dimension | Conventional Multi-Framework Stack (External ASGI/WSGI + Jinja2 + SPA + npm) | `zcg.web` Pure Python 3.14 Hypermedia + ES2024 Islands |
| :--- | :--- | :--- |
| **Runtime Dependencies & Build Pipeline** | Dozens of transitive Python + hundreds of npm packages; mandatory bundler/transpiler step on every UI edit. | `dependencies == []` (`0` npm/bundler steps, `0` transitive CVE churn); live `<ws>/surfaces/web/` overlays with `OVERLAY_BOOT_QUARANTINED` safety net. |
| **Templating & HTML Safety** | Full expression evaluators (e.g., Jinja2) with SSTI attack surface and manual escape auditing. | `< 380`L regex-free AST (`TemplateCatalog`, `0` arbitrary-expression evaluation) + Python 3.14 `PEP 750` `html_t(t"...") -> SafeHTML` (`:url`, `:mailto_url`, `:join`). |
| **Client Interactivity & AuthZ Boundary** | External `htmx.js` or SPA DTO duplication requiring mirrored client-side state & authorization checks. | `< 310`L audited ES2024 `zcg-swap.js` (`node --check`, `0` `'unsafe-inline'` CSP) + `[data-island]` `ZCGHydrator`, preserving single-boundary `R0..R3` server truth. |

1. **Zero-Build Two-World Sovereignty & Supply-Chain Longevity**: Keeping `dependencies == []` (`0` npm/bundler steps, `0` transitive CVE churn) allows any individual or department to customize `<ws>/surfaces/web/{templates,static}/` and `--zcg-*` CSS tokens live while the Golden Core (`importlib.resources`) updates conflict-free underneath (`OVERLAY_BOOT_QUARANTINED` safety net).
2. **Python 3.14 Native Language Primitives (`PEP 703` Free-Threading + `PEP 649/695` + `PEP 750` `string.templatelib` `html_t`)**: Modern Python 3.14 eliminates the historical ergonomic and concurrency gaps that forced teams onto heavy external frameworks — pairing `TemplateCatalog` (`< 380`L regex-free AST, `0` SSTI arbitrary-expression evaluation unlike Jinja2) with native `PEP 750` `html_t(t"...") -> SafeHTML` (`:url`, `:mailto_url`, `:join` auto-escaping/sanitization).
3. **Single-Language Domain Truth & Audited Hypermedia (`zcg-swap.js` + `[data-island]`)**: Replaces generic external `htmx.js` + SPA DTO layers with `< 310`L audited ES2024 `zcg-swap.js` (`node --check`, `0` `'unsafe-inline'` CSP) natively integrating Double-Submit HMAC CSRF, `HTTP 286` poll-stop, `?ws_scope=` propagation, and progressive `ZCGHydrator` islands without client-server `R0..R3` authorization drift.

`src/zcg/web/` and `src/zcg/platform/` declare explicit `excluded_contexts` in [`system/zcg-node.json`](../../system/zcg-node.json) blocking any runtime import from `topology`, `capsules`, `ephemeral`, `governance`, `plugins`, `providers`, `cockpit`, `mcp`, or `cli` (and `src/zcg/web/` additionally excludes `platform`). Every HTTP/ASGI route binds one of the `16` valid `Zone (Z1..Z4) × Tier (T1..T5)` `DeliveryChannel` values:

| Zone (`Presentation`) | Allowed Tiers (`T1..T5`) | Derived `CommPattern` | Zone-Graded `Content-Security-Policy` (`script-src` / `connect-src`) |
| :--- | :--- | :--- | :--- |
| **`Z1` (`static`)** | `T1` (`STATIC_SYNC` only; `Z1 × T2..T5` rejected) | `request_response` | `script-src 'none'; frame-ancestors 'none'` (`0 KB` client JS enforced by browser) |
| **`Z2` (`swap`)** | `T1..T5` (`SWAP_SYNC..SWAP_PIPELINE`) | `T1`: `request_response`; `T2,T4`: `polling`; `T3,T5`: `sse` | `script-src 'self'; connect-src 'self'; frame-ancestors 'none'` |
| **`Z3` (`island`)** | `T1..T5` (`ISLAND_SYNC..ISLAND_PIPELINE`) | `T1`: `request_response`; `T2,T4`: `polling`; `T3,T5`: `sse` | `script-src 'self'; connect-src 'self'; frame-ancestors 'none'` (`0` `'unsafe-inline'`) |
| **`Z4` (`immersive`)** | `T1..T5` (`IMMERSIVE_SYNC..IMMERSIVE_PIPELINE`) | `T1`: `request_response`; `T2,T4`: `polling`; `T3`: `websocket`; `T5`: `sse` | `script-src 'self' 'wasm-unsafe-eval'; connect-src 'self' ws: wss:` (`0` `'unsafe-inline'`) |

1. **Defense-in-Depth `Z1..Z4` `CSRF` (Double-Submit HMAC + `Sec-Fetch-Site` / `Origin`), `Permissions-Policy` & Signed Cookies (`security.py`)**: Every response includes `Permissions-Policy` (`camera=(), microphone=(), geolocation=(), payment=(), usb=()`) and `Cross-Origin-Resource-Policy: same-origin`. Mutating `POST|PUT|PATCH|DELETE` requests across `Z1..Z4` enforce W3C Fetch Metadata (`Sec-Fetch-Site: cross-site` blocked unconditionally), `Origin` vs. `Host` parity, and constant-time Double-Submit HMAC verification (`issue_csrf_token` / `verify_double_submit_csrf` binding `zcg_csrf` cookie + `x-zcg-csrf-token` header across `Z1`/`Z2` and cookie-bearing `Z3`/`Z4` browser sessions, while allowing pure stateless non-cookie `Bearer` API callers on `Z3`/`Z4`). Stateless session payloads are sealed via `sign_cookie_value` / `verify_cookie_value` (`base64url(canonical_json) + "." + hmac_sha256_hex`).
2. **Scoped Internal CDN `CSP` Graduation & Mandatory `sha384` `SRI` (`security.py`, `factory.py`)**: By default (`allowed_cdn_origins = ()`), `build_zone_security_headers` emits strict `'self'` origins (`script-src 'none'` on `Z1`). When governed `https://cdn.<canonical_domain>` origins are supplied, `normalize_cdn_origins` validates origin purity (`0` wildcards, paths, or non-loopback `http://`), appends them to `style-src`/`img-src`/`font-src` (and `script-src`/`connect-src` on `Z2..Z4` while keeping `Z1` `script-src 'none'`), and `verify_sri_external_assets` blocks any HTML response referencing an external `<script src>` or `<link rel="stylesheet" href>` without an allowed CDN origin, `integrity="sha384-..."` (`compute_sri_sha384`), and `crossorigin` (`500 SRI_POLICY_VIOLATION`).
3. **Dual Error Adaptation (`WebAppError`)**: Raising `WebAppError` returns an escaped `<div class="zcg-alert ... zcg-error ...">` HTML swap fragment when `request.is_partial_swap` is `True` and a structured JSON envelope (`error`, `message`, `severity`, `action`, `user_hint`) otherwise.

## 3. Typed `Request`, `APIRouter`, `HTTPMiddleware` Pipeline & OpenAPI 3.1 (`request.py`, `router.py`, `middleware.py`, `factory.py`)

The backend API layer provides ergonomic routing, composable middleware/guards, form/multipart parsing, and automatic schema generation using 100% Python 3.14 stdlib:

1. **Typed `Request` & Streaming Body Parsers (`request.py`)**:
   - `read_bounded_body` streams ASGI `http.request` chunks while aborting immediately with `413 PAYLOAD_TOO_LARGE` when `content-length` or cumulative bytes exceed `max_payload_bytes`.
   - `Request.json()` decodes JSON payloads (`400 INVALID_JSON` on syntax errors); `Request.form()` / `Request.form_multi()` parse `application/x-www-form-urlencoded` bodies via `urllib.parse.parse_qs`; and `Request.multipart()` parses `multipart/form-data` streams via stdlib `email.parser.BytesFeedParser(policy=email.policy.HTTP)`, sanitizing `UploadFile.filename` basenames to prevent directory traversal.
2. **Composable `APIRouter`, `RouteGuard`s, `HTTPMiddleware`, `allowed_hosts` & `CORSPolicy` (`router.py`, `middleware.py`)**:
   - `APIRouter` compiles `{param}` templates into deterministic `/`-delimited segment tuples (`0` regular expressions, validating `str.isidentifier()` parameter names), merges outer-to-inner `RouteGuard` sequences across routers and `include_router`, distinguishes `404` vs. `405 Method Not Allowed` (`Allow` header), and synthesizes OpenAPI `3.1.0` documents (`compose_openapi_document`, `render_openapi_docs_html`).
   - `compose_http_pipeline` wraps handlers with ordered `HTTPMiddleware` layers, `enforce_allowed_hosts` (`400 INVALID_HOST_HEADER` over `urllib.parse.urlsplit` preventing `Host`-header poisoning), opt-in `CORSPolicy` (forbidding wildcard `"*"` with `allow_credentials=True` via `CORS_WILDCARD_CREDENTIALS_FORBIDDEN` and handling `OPTIONS` preflight `204`/`403`), and `make_bulkhead_middleware` (`503 BULKHEAD_SHIELDED` saturation shedding while exempting `/healthz`).
3. **Adaptive Responses (`respond`, `respond_poll`, `respond_empty`) & Styled OpenAPI Explorer (`/docs`)**:
   - `respond` returns `SWAP_SYNC` HTML fragments on partial swap requests, `ISLAND_SYNC` full pages when `full_html` is provided on standard navigation, and `ISLAND_SYNC` JSON payloads for API callers. `respond_poll` emits `HTTP 200` while active and **`HTTP 286`** (`Stop Polling`) when `done=True`.
   - When `DocsAccessMode` permits access, `GET /docs` renders a styled zero-build HTML5 OpenAPI 3.1 Route & `DeliveryChannel` Explorer (`/static/css/*.css`, method pills, `x-delivery-channel` badges, summaries, `/openapi.json`, and `/dashboard` navigation). When `DocsAccessMode.DISABLED` is active (default in `pro`), `GET /docs` returns `HTTP 404` (`DOCS_DISABLED`, `ErrorSeverity.INFO`) with an explicit `user_hint` explaining production API surface hardening.

## 8. Transport TLS 1.3 / mTLS, Trusted Reverse-Proxy `X-Forwarded-Proto` & `HSTS` (`tls.py`, `server.py`)

`src/zcg/web/auth/tls.py` unifies transport confidentiality across all four operational deployment topologies using Python 3.14's C-backed `ssl` (`OpenSSL 3`) and `ipaddress` stdlib modules (`0` external packages):

1. **Loopback W3C Secure Context (`127.0.0.1` / `::1` / `*.localhost`)**: Plaintext HTTP remains permitted exclusively on loopback interfaces (`isSecureContext = true` per W3C *Secure Contexts* & RFC 6761), keeping `HSTS` disabled so local ports are never poisoned.
2. **Non-Loopback Plaintext Guard (`PLAINTEXT_NON_LOOPBACK_BLOCKED`)**: Binding `serve_asgi_loopback` or `zcg-mcp --http-port` to any non-loopback address (`0.0.0.0` or LAN IP) raises `PLAINTEXT_NON_LOOPBACK_BLOCKED` unless native TLS certificates (`--tls-certfile` + `--tls-keyfile`) or an explicit edge-terminated proxy contract (`--behind-tls-proxy`) are configured.
3. **Native `ssl.SSLContext` TLS 1.3 & Optional mTLS (`build_server_ssl_context`)**: Enforces `TLSVersion.TLSv1_2` floor (preferring `TLS 1.3`), disables TLS compression, and activates `ssl.CERT_REQUIRED` mutual TLS when `--tls-client-ca` is supplied.
4. **Trusted Proxy Scheme & Automatic HTTPS Hardening (`is_https_scope`, `HSTS`, `; Secure`)**: `resolve_effective_request_scheme` honors `X-Forwarded-Proto: https` strictly when `peer_host` matches `trusted_proxy_hosts` (exact host/IP or CIDR such as `10.0.0.0/8`), activating `Strict-Transport-Security: max-age=63072000; includeSubDomains`, `upgrade-insecure-requests`, and `; Secure` cookies in `create_web_app`.
