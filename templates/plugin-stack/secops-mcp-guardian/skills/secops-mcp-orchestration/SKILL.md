# Skill: Pure-Bot Security Department MCP Orchestration (`secops-mcp-orchestration`)

> Operationalizes a **Pure-Bot Transversal Security Department (`dept-security`, `precedence: 7`)** that audits Fixed departmental MCPs and coordinates Ephemeral Security MCP leases.

---

## 1. Autonomous Scope-Bounded Audit of Fixed Departmental MCPs (`R0..R2`)

1. Inspect the capability profile and active leases across target departments via `orchestrate_ephemeral_fork(action="catalog")` (`mcp_autonomy_matrix`).
2. Verify `NIST-01..04` controls, `citation_receipt` integrity (`CITATION_DRIFT_DETECTED`), and `Q1..Q4` telemetry radar (`audit_node_drift`) across each department's Fixed MCP (`corporate-root-hub`, `node-work-cockpit`, `tutor-study-cockpit`, and `google-cloud-iac` workloads) in `strictly-read-only` mode.

## 2. Actionable Ephemeral MCP Spawn & Cross-Departmental Proposal (`W` Rings)

1. Spawn a scoped ephemeral lease via `orchestrate_ephemeral_fork(action="spawn", bot_role="secops-mcp-orchestrator-bot")` (or project branch rules via `action="project-branch"` / `DMCP` without working-tree checkout).
2. Seal the 4-Channel Executive Digest (`action="seal-return"`), reap the ephemeral sandbox (`action="reap"`), and stage any required remediation proposal in `.agents/proposals/` or `WORKTASK.md`.
